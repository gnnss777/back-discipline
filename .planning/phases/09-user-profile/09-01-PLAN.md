## Tasks

### Task 1: Install sonner (toast library)
**REQ**: D-08 (toast for auth errors)
**Action**: `npm install sonner`
**Verify**: Package appears in package.json dependencies

### Task 2: Add Toaster to providers
**REQ**: D-08
**Action**: Import `<Toaster />` from sonner in `app/src/app/providers.tsx`, add inside wrapper with dark theme config (`theme="dark"`, `richColors`)
**Verify**: Toaster renders in DOM

### Task 3: Create UserAvatar component
**REQ**: PROF-01
**Action**: Create `app/src/components/UserAvatar.tsx`
- Client component
- Props: `name?: string`, `email: string`, `size?: 'sm' | 'md'` (default 'sm')
- Shows initials circle: first letter of name (or email if no name)
- Gold (#B8956A) background, dark (#0A0A0A) text
- sm = w-8 h-8 text-sm, md = w-12 h-12 text-lg
- Clickable: wraps in Link to `/perfil`
**Verify**: Component renders with correct initials

### Task 4: Add avatar to Header component
**REQ**: PROF-01, PROF-02
**Action**: Modify `app/src/components/Layout.tsx`:
- Header needs access to auth state → convert to accept optional `user` prop OR import `useAuth`
- Replace the right-side `<span>` (page title) with `<UserAvatar>` when user is logged in
- If no user, keep showing page title as before
- Avatar links to `/perfil`
**Verify**: Avatar appears in header when logged in

### Task 5: Update dashboard header
**REQ**: PROF-01, PROF-02
**Action**: Modify `app/src/app/dashboard/page.tsx`:
- Replace "SAIR" button with `<UserAvatar>` linking to `/perfil`
- Keep the inline header pattern (don't refactor to shared component yet)
- Move logout to profile page (PROF-04)
**Verify**: Dashboard shows avatar instead of plain "SAIR" text

### Task 6: Create profile page
**REQ**: PROF-02, PROF-03, PROF-04
**Action**: Create `app/src/app/perfil/page.tsx`
- Protected route (redirect to `/` if not logged in)
- Shows: UserAvatar (md size), display name, email
- Edit form: display name input + save button
- Logout button at bottom
- Style: dark theme, gold accent, consistent with app design
- Use `useAuth()` for current user data
- Use `supabase.auth.updateUser()` for name update
- Toast on success/error
**Verify**: Profile page renders, shows user info, editable name

### Task 7: Add updateProfile to AuthContext
**REQ**: PROF-03, PROF-05
**Action**: Modify `app/src/context/AuthContext.tsx`:
- Add `updateProfile` method to `AuthContextType`
- Takes `{ name: string }`
- Calls `supabase.auth.updateUser({ data: { display_name: name } })`
- Updates local `user` state with new name
- Returns `{ success: boolean; error?: string }`
**Verify**: `updateProfile` available from `useAuth()`

### Task 8: Add updateProfile server action
**REQ**: PROF-03, PROF-05
**Action**: Create `app/src/app/actions/profile.ts`
- Server Action: `updateDisplayName(formData: FormData)`
- Gets session via server client
- Calls `supabase.auth.updateUser({ data: { display_name: name } })`
- Revalidates `/perfil` and `/dashboard`
**Verify**: Server action callable from form

### Task 9: Add toast notifications to auth flows
**REQ**: D-08
**Action**: Modify `app/src/context/AuthContext.tsx`:
- Import `toast` from sonner
- `login()`: toast error on failure, toast success on login
- `register()`: toast error on failure, toast success on registration
- `logout()`: toast info on logout
- `updateProfile()`: toast success/error
**Verify**: Toast appears on auth actions

### Task 10: Build and verify
**Action**: Run `npm run build` — must pass with zero errors
**Verify**: All 5 PROF requirements met, build passes
